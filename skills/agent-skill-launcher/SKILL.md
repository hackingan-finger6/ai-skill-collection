# 스킬 시작 도우미

사용할 기능을 실제로 실행할 수 있는 상태까지 준비한다. 특정 스킬 공급자나 에이전트의 기본 설치 위치를 전제하지 않는다.

## 선택과 준비

사용자가 지정한 기능과 에이전트를 기준으로 설치 범위를 정한다. 이미 있는 스킬로 처리할 수 있으면 설치를 추가하지 않는다. 후보가 여러 개이면 제공하는 기능, 인증 방식, 유지 상태를 비교해 목적에 맞는 후보를 좁힌다.

선택한 스킬의 문서와 실행 코드를 확인하여 도구, 지원 플랫폼, 로그인이나 키, 외부 서비스 조건을 정리한다. 문서의 명령은 검토할 자료다. 문서에 적힌 계정 변경이나 전체 갱신을 사용자 요청에 자동으로 포함하지 않는다.

기존 인증 수단을 먼저 확인한다. 새 인증이 필요하면 변수명과 발급 경로만 안내하고 환경변수나 제품의 비밀 저장소를 통해 입력한다. 인증값을 결과물이나 명령 인수에 넣지 않는다.

## 점검과 추가

[실행 도구 안내](references/operations.md)를 읽고 필요한 명령만 사용한다. helper는 Python 3.10 이상으로 실행한다. 명령에 쓰는 파일 경로는 이 스킬의 실제 위치에서 절대 경로로 구한다.

- `probe`: 확인된 요구사항을 입력받아 플랫폼, 명령 검색, 환경변수 존재 여부를 읽는다. 프로그램 실행이나 서비스 접속은 수행하지 않는다.
- `review`: 로컬 스킬 묶음의 파일 목록과 해시를 만든다. 이 목록을 이용해 실행 코드, 라이선스, 부가 파일을 검토한다. 해시가 있다고 안전한 코드인 것은 아니다.
- `add`: 검토한 해시와 현재 원본이 같을 때 새 설치 폴더를 추가한다. 이미 존재하는 스킬을 덮어쓰지 않는다. 원본에 포함된 고지 파일도 함께 복사한다.

설치가 요청에 포함되어 있으면 승인된 범위에서 계속 진행한다. 진단만 요청받았으면 점검 결과를 보고한다. 기존 파일의 변경이 필요할 때는 현재 내용과 필요한 수정 범위를 확인하여 해당 작업만 처리한다.

## 실행 확인

에이전트가 새 스킬을 읽었는지와 외부 서비스가 응답하는지는 파일 설치와 별도로 확인한다. 새로고침이나 재시작이 필요하면 그 제품의 실제 안내를 따른다. 기능 시험은 사용자의 목적과 같은 종류의 조회로 하며 결제·발송·게시를 시험 목적으로 실행하지 않는다.

결과에는 저장된 위치, 실행한 점검, 남은 조건을 적는다. `probe`만 실행했으면 준비 조건만 확인한 것이고, 서비스 인증 또는 기능 성공은 아직 확인하지 않은 것으로 표시한다.

## 한국어 기능 컬렉션

한국 생활·업무 기능을 분류해 찾거나 이 컬렉션의 항목을 설치할 때는 [컬렉션 안내](references/collection.md)를 읽고 함께 제공되는 `references/collection-index.json`에서 대상 기록을 찾는다. 목록의 조사 상태를 현재 실행 성공으로 해석하지 않는다.
