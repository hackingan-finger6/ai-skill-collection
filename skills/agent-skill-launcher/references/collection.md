# 컬렉션 목록 사용

이 스킬과 함께 설치되는 `collection-index.json`에 125개 기능의 분류·요약·원문 링크·설치 출처가 있다. 목록 확인은 설치 실행을 의미하지 않는다.

사용자가 용도를 말하면 목록의 `summary`와 `limits`를 읽어 후보를 좁힌다. 스킬 이름을 지정하면 해당 기록의 원문을 확인한다. 현재 기록은 문서 조사를 바탕으로 하며 실행 준비 상태를 확정하지 않는다.

설치가 요청된 경우 `install.repository`, `install.ref`, `install.path`를 공식 skill-installer에 전달하거나 검토한 로컬 묶음을 `launcher.py`로 추가한다. 기존 스킬을 덮어쓰지 않고 Codex만 대상으로 작업한다. 기록의 고정 버전과 다른 버전으로 바꿀 때는 목록과 요구사항이 달라졌는지 확인한다.

사용자가 설치를 중단하거나 설치하지 말라고 하면 목록·설명 작업만 수행한다. 전체 설치는 전체가 명시적으로 요청된 경우에만 실행한다. 분류별 보관은 관리 도우미에서 실제 의존 관계와 보존 대상을 확인한 다음 처리한다.

플랫폼·인증 준비는 개별 지침에서 다시 확인한다. 초기 목록의 실행 경로에는 원 공급자의 CLI·프록시를 사용하는 항목이 있다. 이 도우미가 그 서비스까지 자체 구현한 것으로 설명하지 않는다.
