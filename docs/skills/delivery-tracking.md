# 택배 배송조회

**분류:** [생활·쇼핑·건강](../categories/daily.md) · **스킬 ID:** `delivery-tracking`

## 활용

CJ대한통운·우체국 송장의 배송 상태 확인에 활용할 수 있는 기능입니다.

## 범위와 준비사항

- 두 택배사 지원 문서 기준
- 플랫폼: 기능별 문서 확인 필요
- 인증: 기능별 문서에서 사용자 키·로그인·공개 조회를 확인; 인증 성공 미검증
- 확인 상태: 문서 조사 완료, 실제 기능 실행 미검증.

## 설치 요청 예시

```text
스킬 시작 도우미로 delivery-tracking의 원문과 요구사항을 확인하고,
Codex에 이 스킬만 설치한 뒤 안전한 조회 예제로 확인해줘.
```

이 문서는 설치를 실행하지 않습니다. 전체 설치가 아닌 개별 선택 예시입니다.
