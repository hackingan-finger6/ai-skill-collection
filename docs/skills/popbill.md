# 팝빌 업무 API

**분류:** [사업·창업·업무](../categories/business.md) · **스킬 ID:** `popbill`

## 활용

세금계산서·현금영수증·홈택스 수집·메시지 등 업무 API 연결에 활용할 수 있는 기능입니다.

## 범위와 준비사항

- 개인 인증·권한·사용 요금 필요; 기능별 발행·전송 포함
- 플랫폼: 기능별 문서 확인 필요
- 인증: 기능별 문서에서 사용자 키·로그인·공개 조회를 확인; 인증 성공 미검증
- 확인 상태: 문서 조사 완료, 실제 기능 실행 미검증.

## 설치 요청 예시

```text
스킬 시작 도우미로 popbill의 원문과 요구사항을 확인하고,
Codex에 이 스킬만 설치한 뒤 안전한 조회 예제로 확인해줘.
```

이 문서는 설치를 실행하지 않습니다. 전체 설치가 아닌 개별 선택 예시입니다.
