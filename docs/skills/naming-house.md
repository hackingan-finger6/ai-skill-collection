# 작명소

**분류:** [운세·작명](../categories/interpretation.md) · **스킬 ID:** `naming-house`

## 활용

사주·성명학·한자 획수·발음 기준 이름 추천에 활용할 수 있는 기능입니다.

## 범위와 준비사항

- 성명학 참고 점수; 인명용 한자·개명 검증 별도
- 플랫폼: 기능별 문서 확인 필요
- 인증: 기능별 문서에서 사용자 키·로그인·공개 조회를 확인; 인증 성공 미검증
- 확인 상태: 문서 조사 완료, 실제 기능 실행 미검증.

## 설치 요청 예시

```text
스킬 시작 도우미로 naming-house의 원문과 요구사항을 확인하고,
Codex에 이 스킬만 설치한 뒤 안전한 조회 예제로 확인해줘.
```

이 문서는 설치를 실행하지 않습니다. 전체 설치가 아닌 개별 선택 예시입니다.
