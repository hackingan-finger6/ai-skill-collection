# 근처 응급실 병상 상태 확인

**분류:** [생활·쇼핑·건강](../categories/daily.md) · **스킬 ID:** `emergency-room-beds`

## 활용

근처 응급실 운영·병상 운영 표시와 갱신시각 확인에 활용할 수 있는 기능입니다.

## 범위와 준비사항

- 정확한 실시간 잔여 병상 수·가동률 미제공
- 플랫폼: 기능별 문서 확인 필요
- 인증: 기능별 문서에서 사용자 키·로그인·공개 조회를 확인; 인증 성공 미검증
- 확인 상태: 문서 조사 완료, 실제 기능 실행 미검증.

## 설치 요청 예시

```text
스킬 시작 도우미로 emergency-room-beds의 원문과 요구사항을 확인하고,
Codex에 이 스킬만 설치한 뒤 안전한 조회 예제로 확인해줘.
```

이 문서는 설치를 실행하지 않습니다. 전체 설치가 아닌 개별 선택 예시입니다.
