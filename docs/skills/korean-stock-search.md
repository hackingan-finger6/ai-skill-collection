# 한국 주식 정보 조회

**분류:** [금융·투자·통계](../categories/finance.md) · **스킬 ID:** `korean-stock-search`

## 활용

한국 상장종목 기본정보·일별 시세 조회에 활용할 수 있는 기능입니다.

## 범위와 준비사항

- 일별 공개 시세; 실시간 거래 기능과 구분
- 플랫폼: 기능별 문서 확인 필요
- 인증: 기능별 문서에서 사용자 키·로그인·공개 조회를 확인; 인증 성공 미검증
- 확인 상태: 문서 조사 완료, 실제 기능 실행 미검증.

## 설치 요청 예시

```text
스킬 시작 도우미로 korean-stock-search의 원문과 요구사항을 확인하고,
Codex에 이 스킬만 설치한 뒤 안전한 조회 예제로 확인해줘.
```
