# 국가데이터처 KOSIS 통계 조회

**분류:** [금융·투자·통계](../categories/finance.md) · **스킬 ID:** `kosis-stats`

## 활용

KOSIS 통계표 검색·항목·단위·수치 조회에 활용할 수 있는 기능입니다.

## 범위와 준비사항

- 기본 프록시; 대용량·직접 조회는 개인 인증키 필요
- 플랫폼: 기능별 문서 확인 필요
- 인증: 기능별 문서에서 사용자 키·로그인·공개 조회를 확인; 인증 성공 미검증
- 확인 상태: 문서 조사 완료, 실제 기능 실행 미검증.

## 설치 요청 예시

```text
스킬 시작 도우미로 kosis-stats의 원문과 요구사항을 확인하고,
Codex에 이 스킬만 설치한 뒤 안전한 조회 예제로 확인해줘.
```
