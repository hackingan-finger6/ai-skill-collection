# 지급명령 신청 보조

**분류:** [리서치·공공정보](../categories/research.md) · **스킬 ID:** `court-payment-order-assistant`

## 활용

지급명령 신청서 초안·청구정보·증빙 목록 정리에 활용할 수 있는 기능입니다.

## 범위와 준비사항

- 로그인 이후 입력 준비; 최종 제출과 구분
- 플랫폼: 기능별 문서 확인 필요
- 인증: 기능별 문서에서 사용자 키·로그인·공개 조회를 확인; 인증 성공 미검증
- 확인 상태: 문서 조사 완료, 실제 기능 실행 미검증.

## 설치 요청 예시

```text
스킬 시작 도우미로 court-payment-order-assistant의 원문과 요구사항을 확인하고,
Codex에 이 스킬만 설치한 뒤 안전한 조회 예제로 확인해줘.
```
