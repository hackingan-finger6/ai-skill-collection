# 한국 개인정보처리방침·이용약관 자동 생성

**분류:** [리서치·공공정보](../categories/research.md) · **스킬 ID:** `korean-privacy-terms`

## 활용

웹서비스의 개인정보처리방침·이용약관·동의 화면 초안 생성에 활용할 수 있는 기능입니다.

## 범위와 준비사항

- Next.js 프로젝트 대상; 업스트림 스킬 연결
- 플랫폼: 기능별 문서 확인 필요
- 인증: 기능별 문서에서 사용자 키·로그인·공개 조회를 확인; 인증 성공 미검증
- 확인 상태: 문서 조사 완료, 실제 기능 실행 미검증.

## 설치 요청 예시

```text
스킬 시작 도우미로 korean-privacy-terms의 원문과 요구사항을 확인하고,
Codex에 이 스킬만 설치한 뒤 안전한 조회 예제로 확인해줘.
```
