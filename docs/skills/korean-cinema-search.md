# 영화관 검색

**분류:** [교육·문화·스포츠](../categories/culture.md) · **스킬 ID:** `korean-cinema-search`

## 활용

CGV·메가박스·롯데시네마 상영시간·잔여석 검색에 활용할 수 있는 기능입니다.

## 범위와 준비사항

- 조회 결과 시점 기준
- 플랫폼: 기능별 문서 확인 필요
- 인증: 기능별 문서에서 사용자 키·로그인·공개 조회를 확인; 인증 성공 미검증
- 확인 상태: 문서 조사 완료, 실제 기능 실행 미검증.

## 설치 요청 예시

```text
스킬 시작 도우미로 korean-cinema-search의 원문과 요구사항을 확인하고,
Codex에 이 스킬만 설치한 뒤 안전한 조회 예제로 확인해줘.
```

이 문서는 설치를 실행하지 않습니다. 전체 설치가 아닌 개별 선택 예시입니다.
기능 스킬의 원문과 실제 실행 코드는 아래 출처에서 제공됩니다.
