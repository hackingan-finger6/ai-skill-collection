# 네이버 쇼핑 가격비교

**분류:** [생활·쇼핑·건강](../categories/daily.md) · **스킬 ID:** `naver-shopping-search`

## 활용

네이버 쇼핑 상품의 표시가격·판매처 비교에 활용할 수 있는 기능입니다.

## 범위와 준비사항

- 조회한 후보 범위의 가격 비교; 전 상품 최저가 보장 제외
- 플랫폼: 기능별 문서 확인 필요
- 인증: 기능별 문서에서 사용자 키·로그인·공개 조회를 확인; 인증 성공 미검증
- 확인 상태: 문서 조사 완료, 실제 기능 실행 미검증.

## 설치 요청 예시

```text
스킬 시작 도우미로 naver-shopping-search의 원문과 요구사항을 확인하고,
Codex에 이 스킬만 설치한 뒤 안전한 조회 예제로 확인해줘.
```

이 문서는 설치를 실행하지 않습니다. 전체 설치가 아닌 개별 선택 예시입니다.
