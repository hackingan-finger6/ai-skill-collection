# HWP 문서 조회/변환

**분류:** [개발·문서·자동화](../categories/development.md) · **스킬 ID:** `hwp`

## 활용

HWP·HWPX 내용 추출·변환·문서 비교·양식 필드 확인에 활용할 수 있는 기능입니다.

## 범위와 준비사항

- 문서 파싱·변환 기능
- 플랫폼: 기능별 문서 확인 필요
- 인증: 기능별 문서에서 사용자 키·로그인·공개 조회를 확인; 인증 성공 미검증
- 확인 상태: 문서 조사 완료, 실제 기능 실행 미검증.

## 설치 요청 예시

```text
스킬 시작 도우미로 hwp의 원문과 요구사항을 확인하고,
Codex에 이 스킬만 설치한 뒤 안전한 조회 예제로 확인해줘.
```

이 문서는 설치를 실행하지 않습니다. 전체 설치가 아닌 개별 선택 예시입니다.
