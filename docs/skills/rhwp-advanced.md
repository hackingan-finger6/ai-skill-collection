# HWP 레이아웃·IR 디버깅

**분류:** [개발·문서·자동화](../categories/development.md) · **스킬 ID:** `rhwp-advanced`

## 활용

HWP 레이아웃·내부 구조·버전 차이·썸네일 검사에 활용할 수 있는 기능입니다.

## 범위와 준비사항

- 고급 문서 진단 도구
- 플랫폼: 기능별 문서 확인 필요
- 인증: 기능별 문서에서 사용자 키·로그인·공개 조회를 확인; 인증 성공 미검증
- 확인 상태: 문서 조사 완료, 실제 기능 실행 미검증.

## 설치 요청 예시

```text
스킬 시작 도우미로 rhwp-advanced의 원문과 요구사항을 확인하고,
Codex에 이 스킬만 설치한 뒤 안전한 조회 예제로 확인해줘.
```

이 문서는 설치를 실행하지 않습니다. 전체 설치가 아닌 개별 선택 예시입니다.
기능 스킬의 원문과 실제 실행 코드는 아래 출처에서 제공됩니다.
